## 本期内容（第一章 全等图形）

5 个经典解题模型，每个模型包含 PNG 静态图、.ggb 源文件、可交互 HTML 三件套：

1. **1.1 图形折叠模型** — 反射变换，折叠前后全等，折痕为对称轴
2. **1.2 双垂线段模型** — 一线三等角直角特例，△ACE≌△BAD
3. **1.3 共点互余模型** — 公共顶点两全等直角三角形，∠AFE=90°定值
4. **1.4 角平分线模型** — 角两边截取等线段构造全等△ADP≌△AEP
5. **1.5 角含半角模型** — 正方形∠EAF=45°时EF=BE+DF，旋转构造全等
